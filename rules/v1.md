# Ruleset 5 — experimental (restored)

V0.5.1 restores the scoring policy used before the rejected ruleset-6 change. All 22 registered rules are scored again, with their original budgets, thresholds, deductions, applicability, foundational caps and ownership. Open-only audits and the minimal Refresh UI are unchanged. The policy filename is retained for existing CLI/documentation references.

These are explicit engineering rules. WCAG ratios use standard calculations; OKLab/state thresholds and severity bands are published project heuristics, not universal accessibility certification. Changing budgets, thresholds, ownership, models or applicability requires a ruleset change and reviewed goldens.

The higher foundation/menu budgets prioritize persistent base content and selected-row text. Tooltip receives lower weight because it is secondary, not because its common translucent default should pass. An unresolved surface remains unassessed and makes the grade provisional; it is not a pass. Text is not assumed to be large from unknown runtime font settings.

## Applicability, context, and ownership

All 22 rules are expected for the supported profile. Missing inputs are not automatically exempted. Rules that depend on a runtime behavior the analyzer cannot verify are unassessed ("paused"); if palette loading itself is unverified, every rule is (see `docs/supported-runtime.md`). Absent theme `shell.toml` uses supported runtime defaults; its absence is not a defect. Broken foundational inputs retain blocking caps; unmeasured checks remain visible limitations rather than preventing all grades.

Palette parsing owns syntax, roles owns unresolved foundational context; downstream contrast is unassessed rather than deducted again. Background validity owns corruption. Core readability owns each opaque/reference-surface text deficit, including sampled wallpaper-backed lock deficits. Shell fill cues do not score text contrast or claim complete control accessibility. Wallpaper rules own additional degradation under their specific sampled model; a reference deficit already scored in core readability is retained as wallpaper evidence without a second charge.

Multiple images and sampled video frames share each wallpaper rule's budget through the minimum measured contrast. Any incomplete expected media set leaves the entire media-dependent rule unassessed. Repeated identical media is decoded once by content hash, but its bytes/roles remain in the fingerprint. Video is valid supported media, not a theme defect; unavailable codecs/tools, HDR/color-management requirements or operational limits create limitations. No number of files can multiply a rule's budget.

Scored text pairs require supported colors and an opaque surface, complete sampled lock wallpaper context, or the explicit `application-gray17-v4` background scenario. Seventeen black-to-white reference backgrounds grade translucent application-backed text/fills/borders without claiming live pixels or all possible RGB content. Solid role references resolve recursively with cycle detection. Native popup-border gradients sample 17 points per adjacent pair of 2–8 color stops. Native RGB/RGBA/hex border stops preserve alpha, multiply by border-alpha with native byte rounding, and interpolate premultiplied encoded-sRGB components. Unsupported formats stay limitations with an explicit parser/geometry reason; translucency alone does not withhold a supported measurement. No blanket ANSI readability or bright-color lightness scoring is added. Lua syntax remains an unscored advisory, not a certified pass.

Semantic rules measure role visibility, not color-only separation between labeled success/error controls. Terminal selection compares selected and ordinary surfaces separately from selected-text readability. Shared fill checks grade the modeled color cue only. A weak cue incurs a caution, not a full failure inferred from unknown redundant labels/icons/borders. Those additional cues remain outside the assessed fill.

## Score and grade

For assessed unsuppressed budget A and deductions L: `score = 100*(A-L)/A`, overall and per category. Wholly unmeasured categories contribute neither budget nor loss. A ≥90; B ≥80; C ≥70; D ≥60; F below 60, using unrounded scores. Numeric scores remain diagnostic JSON data, not a competing panel percentage.

An expected scored check with missing assessment or suppression makes the overall state provisional; partly measured categories are limited, wholly unmeasured ones not-checked, and wholly inapplicable ones not-applicable. No assessed scored budget means not-graded, with no score or letter. Suppression preserves evidence and is reserved in the model, not exposed as user configuration. Zero-budget advisories do not make grades provisional.

Blocking validity failure caps overall and validity-category A/B/C at D without altering raw scores; F remains F. Foundational failures retain their losses even when downstream checks cannot run. There are no coverage gates or mandatory-check eligibility reasons.

Calculations use f64. Display rounding never decides severity or grade. Golden comparisons allow a 1e-9 numeric tolerance; threshold comparisons themselves do not use it. Non-finite values remain unassessed. A is not WCAG Level AA or a universal accessibility guarantee.
